优先尝试第一个域名，如果无法打开，依次尝试其他地址。部分网络环境需要切换WiFi或4G/5G。

2

清除DNS缓存 (Windows/Mac)

按 Win+R 输入 cmd 后执行 ipconfig /flushdns；Mac 使用 sudo killall -HUP mDNSResponder。可解决解析劫持。

3

修改DNS为公共DNS

推荐使用 1.1.1.1 或 8.8.8.8，能有效防止域名污染。在系统网络设置中修改IPv4 DNS。

4

使用无痕/隐私窗口

部分浏览器插件可能造成干扰，请尝试无痕模式访问，并关闭VPN或代理后再试。

5
